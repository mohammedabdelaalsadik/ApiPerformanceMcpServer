ApiPerformanceMcpServer Execution Plan

Build, run, verify, and demonstrate the .NET 9 MCP API performance server.

1. Prerequisites

  • .NET SDK that can target net9.0
  • An MCP-compatible client
  • Internet access for live API performance tests

2. Build

cd D:\Teaching\Projects\MCP_Test_Performance
dotnet build .\ApiPerformanceMcpServer
Expected result: Build succeeded with 0 Warning(s) and 0 Error(s).

3. Run Manually

dotnet run --project .\ApiPerformanceMcpServer

This is an MCP stdio server. Manual execution starts the process and waits for MCP protocol messages. In normal use, configure an MCP client to launch the command automatically.

4. MCP Client Configuration

{
  "mcpServers": {
    "api-performance": {
      "command": "dotnet",
      "args": [
        "run",
        "--project",
        "D:\\Teaching\\Projects\\MCP_Test_Performance\\ApiPerformanceMcpServer"
      ]
    }
  }
}

5. Available MCP Tools

Tool Purpose
test_api Runs repeated GET or POST requests against one API and returns performance statistics.
compare_apis Runs the same performance test against two APIs and recommends the faster endpoint.

6. Test One API

Prompt:

Test https://httpbin.org/get performance with 5 iterations.

Tool arguments:

{
  "url": "https://httpbin.org/get",
  "method": "GET",
  "iterations": 5
}

7. Compare Two APIs

Prompt:

Compare https://jsonplaceholder.typicode.com/posts and https://httpbin.org/get 10 times and tell me which is faster.

Tool arguments:

{
  "api1Url": "https://jsonplaceholder.typicode.com/posts",
  "api2Url": "https://httpbin.org/get",
  "method": "GET",
  "iterations": 10
}

8. Validate Error Handling

Case Expected Behavior
Invalid URL Returns structured JSON with a failure count and an error message.
Unsupported method Returns structured JSON explaining that only GET and POST are supported.
Timeout or exception Records the exception message in the errors array.

9. Generate Report

cd .\ApiPerformanceMcpServer\Reports
powershell -ExecutionPolicy Bypass -File .\GenerateReportPdf.ps1

Output: ApiPerformanceExecutionReport.pdf

10. Demo Flow

  1. Show the repository structure.
  2. Build the project.
  3. Confirm the MCP client discovers test_api and compare_apis.
  4. Run test_api against https://httpbin.org/get.
  5. Run compare_apis against the two sample APIs.
  6. Open the generated execution report.
